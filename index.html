Add a page

  1. Create pages/<category>/<page-id>/index.html — reuse an existing category folder, or start a new one; it'll show up as its own section automatically.
  2. Give it a real <title> and a <meta name="description"> — that's exactly what the gallery card will show.
  3. Push to main. CI screenshots the page, regenerates the catalog, and deploys — nothing to run yourself, nothing to edit.
