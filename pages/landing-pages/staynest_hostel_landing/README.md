# StayNest Hostel Landing Page

A responsive hostel-discovery landing page built with plain HTML, CSS, and JavaScript. The visual system follows the supplied design brief: white canvas, near-black typography, a single coral accent (#ff385c), rounded surfaces, pill search, photo-first stay cards, light footer, and responsive card grids.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Internet is needed for Google Fonts and the Unsplash photos. The page itself uses no framework or build step.

## Included interactions
- Search by destination, check-in date, and guest count
- Filter stay cards by category
- Save/unsave cards with wishlist hearts
- Account menu, mobile navigation, destination shortcuts, and toast feedback
- Responsive layouts for desktop, tablet, and mobile

Demo hostel names, prices, ratings, and destinations are illustrative. Search is front-end only and does not make bookings.
